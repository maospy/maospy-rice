# maospy-rice

Personalización de Fedora Workstation 44 + GNOME 50 orientada a productividad, desarrollo y manejo de ventanas tipo tiling.

## Base

- Fedora Workstation 44
- GNOME 50
- Wayland

## Características

- Tema Nordic
- Tela Circle Nord Icons
- Wallpaper oficial maospy-rice
- Dash to Dock
- Blur my Shell
- Rounded Window Corners Reborn
- Tiling Shell
- User Themes
- Gaps entre ventanas
- Modo oscuro
- Ventanas redondeadas

## Atajos tiling

Super + Flecha izquierda: mover/encajar izquierda
Super + Flecha derecha: mover/encajar derecha
Super + Flecha arriba: mover/encajar arriba
Super + Flecha abajo: mover/encajar abajo

Super + H: foco izquierda
Super + J: foco abajo
Super + K: foco arriba
Super + L: foco derecha

## Instalación

git clone https://github.com/maospy/maospy-rice.git
cd maospy-rice
chmod +x install.sh
./install.sh

## Desinstalación

Para desinstalar la personalización de Maospy Rice se puede ejecutar:

./uninstall.sh

El desinstalador elimina la personalización de Maospy Rice, pero no elimina automáticamente:

- Google Chrome
- Visual Studio Code
- Spotify
- Node.js
- npm
- Claude Code
- Codex
- Docker
- Docker Compose
- XAMPP
- proyectos o archivos personales
